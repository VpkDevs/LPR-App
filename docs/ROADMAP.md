# Roadmap

## Near-term

- Add sample images and an evaluation script with precision/recall reporting.
- Add configurable country/state plate formats.
- Persist recognition requests and results for auditability.
- Add Docker packaging with a Tesseract-enabled runtime image.

## Future

- Introduce plate localization before OCR for wider camera angles.
- Add async job processing for video frame ingestion.
- Track model/engine versions in recognition metadata.
